## 6. 必须上报、不得静默搁置的两项

### 6.1 conjunction 臂 −1.67%：**已复核，判决比原读数更不利**

**cohort 7/7 完整**，排除了「比较了不同人群」这一解释 —— 这是一次人群可比的真实负增量。

> **p = 0.375 不显著，只说明这 180 题分辨不出 1.67 个百分点（4 vs 1 的不一致对），
> 不说明效应为零。** 负向点估计 + 完整 cohort 应当触发针对性复核，而不是被 p 值挡掉。

**复核已完成**（路线图第 9b 项），结论是把这条读数**换一个说法，而不是把它消掉**：

| 项                 | 判决                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------- |
| **靶向种群零效应** | 六个运行、**121 道 ABS 题**、含两次完整 7/7 cohort → **0 flips**。分解对 ABS 的效应是零              |
| **P2 被证伪**      | P2 预测靶子 `6456829e_abs` 弃权使 ABS → 30/30；实测 ABS **29 → 29**                                  |
| **P3 空洞通过**    | 六对照确实全 0 flips，但整组一题未动 → 「对照没动」不含附带损害的信息                                |
| **代价的位置**     | 全部 4 个回归在 **IE**（**非靶向**能力），且**单向**：六运行中仅 A2 有 1 个反向 flip，其余五运行全 0 |
| **归因**           | 不是「靶向修好了但有代价」，是**「靶向没有任何作用，同时 IE 被系统性拖低」**                         |

**存废：不继续该臂。** 理由不是 p 值，是形状 —— 效应出现在它不该出现的地方，
而它该出现的地方一点没动（完整对账见 `05-longmemeval-sota-analysis/p27-r4-prereg.md` §7）。
