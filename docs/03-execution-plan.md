# Cortex 项目执行推进计划

> 对象：`AgentiX-E/cortex`。内部文档。
> 分工：**本文回答"按什么顺序做、做到什么算过"**；设计要求见 [02](02-technical-design.md)，
> 已完成什么见 [04](04-execution-tracking-report.md)，产品定位见 [01](01-product-whitepaper.md)。
> 纪律：**没有指标的功能不立项；没有消融的机制不算贡献；没有预注册的实验不算证据。**

---

## 0. 结论先行

1. **项目分三段**：设计（已完成）→ 实现（十二步，§2）→ SOTA 攻关（已在进行）。三段的门禁不同，
   混在一起谈是过去多次误判的根源。
2. **实现阶段不从 SOTA 攻关的剩余项开始**，而从**有 POC 或单测可依据**的步骤开始（§2）。
   理由：SOTA 侧剩下的杠杆（换读者、`maxSessionChars`）**都不改变架构**，而架构侧各步
   每一项都有可复跑证据。
3. **验收不用"感觉更好"，用五个数**：逐能力计数（`mean (min–max)`）、配对 McNemar、Wilson
   区间、噪声底、以及"这一轮动了哪个变量"的配置行。
4. **单次运行无法支撑小于 5 道题的声称**（噪声底 MR −2 / TR −4）。这是本计划最硬的一条约束，
   它已经否掉了此前所有 1–3 道题的移动。
5. **回归即回滚**：任何使基准变差的改动，即使理由看似合理，也按实证 revert 或默认关闭
   （先例：图扩散激活 TR 77.95%→70.87%；重排两臂 Δ ±1.33 pp）。
6. **每轮迭代必须交付两样东西**：本条结论的读数，以及**剩余缺口清单 + 关闭它的下一步**、
   直到缺口为空（§12）。

## 4. 测试方法与覆盖率

### 4.1 TDD 铁律

1. 先写失败测试 → 最小实现 → 重构。**测试必须先红**（本轮多次以"改动前 2 个变红"作为证据）。
2. 覆盖四维度（语句/分支/函数/行）**每维 ≥95%**，目标 100%。
3. **禁止 mock**：真实 `better-sqlite3`、`pg-mem`、真实 SQLite-WASM、真实小模型。
4. 属性测试覆盖纯算法：SVD 重构误差、Sinkhorn 双随机收敛、FSRS 单调性、t 分布对称性。
5. 每个新增测试必须能**指名它防的缺陷**；不能指名的测试是分母。

### 4.2 三类"假通过"，各有对策

| 假通过 | 例证 | 对策 |
|---|---|---|
| **检查不可能失败** | `p03` 首版的 `async () => true` | 每个守卫必须有一条**故障注入**测试证明它会红 |
| **生成器选在缺陷不可能发生的点** | `binomialCdf` 的性质测试硬编码 `p = 0.5`（13 处调用里 11 处如此） | 生成器要覆盖缺陷的**定义域边界**；用旧代码反向验证新测试会红 |
| **断言打错层** | 普查测试打在 `countCallers`，缺陷实际在 `censusPackage` | 首轮注入存活即视为"没测到"，而不是"实现对了" |
| **结构性零** | `[POC-6]` 在 1,467 条 persona 语句上读出 0 次泄漏，而发布规则一次都没命中 | 报告任何"零"之前，先报**被测机制的命中次数**；命中为 0 则该列写 `NOT MEASURED` |

### 4.3 覆盖率注解的纪律

`v8 ignore` 不得用来买覆盖率。判定一个注解是否正当，唯一办法是**替换语句体为抛错哨兵**看它是否
可达；且**注解文字本身是第二个扰动旋钮**（曾把守卫连同注解一起替换，测出来的是另一个缺陷）。
清理目标：注解数降到 0，覆盖率仍 ≥95%。

## 5. 评测协议

| 维度 | 要求 |
|---|---|
| **同环境** | 相同 Node 版本、相同 embedding 模型、相同 LLM、相同硬件 |
| **同数据** | 官方 benchmark 全量，不裁剪；**分母必须在产物里写出**（曾出现"曲线对 428 题算、报告对 500 题算"） |
| **同指标** | Top-1 与 Top-5 严格区分；`mean (min–max)` 报逐能力；单次读数必须标"单次" |
| **同种子/温度** | `temperature: 0`；随机算法固定种子 |
| **显著性** | 配对 McNemar（同一批题）；报 Wilson 区间与效应量；**不显著的负向点估计要复核，不能被 p 值挡掉** |
| **噪声底** | 同配置复跑 ≥2 次，净差即带宽；新机制的预注册必须写明"效应 ≥ 2× 该带" |
| **配置行** | 产物必须携带本轮实际生效的配置（`ask` / `reviewPass` / `roles` / `maxPromptChars` / `k` / 单位 / 模型身份） |

**一条判读规则**：同一轮里出现两个互相矛盾的字段（如 `vote=0/0/0`、触达表与 fallthrough 不一致、
普查数咨询次数），**该轮读数作废**，不需要对照、不需要重复 —— 这类矛盾可以机械检出，已做成
`--audit` 七项检查并接进 CI。

## 6. 指标体系

### 6.1 三层

| 层 | 指标 | 为什么必须分开 |
|---|---|---|
| **L1 正确性** | 逐能力正确数、false-share 上界、语义断言通过数、`recall@k` | 错了就谈不上快；这一层是门槛，不是分数 |
| **L2 成本** | p50/p95 延迟、内存、包体、token 与调用次数 | 决定"能不能在标签页里跑" |
| **L3 效用** | 卡片接受率、用户编辑率、平均复核时间 | 决定"值不值得做" |

**L1 不达标则 L2/L3 无意义。**

### 6.2 功能 × 指标 × 测评集

| # | 功能 | L1 | L2 | L3 | 测评集 |
|---|---|---|---|---|---|
| F1 | 浏览器 KV（OPFS-AHP） | 跨重启摘要一致、行数一致、崩溃后无半写 | 写入行/秒、点读 p95、checkpoint 耗时 | 冷启动可交互时间 | `[POC-1]` + 合成 profile（10k/100k 行） |
| F2 | 精确向量扫描 | `recall@10 = 1.0`（精确即定义） | p50/p95、常驻字节 | — | `[POC-1]`/`[POC-2]`；再用真实 embedding 分布复测 |
| F3 | 联邦路由 | 9 条语义断言 + 私有行**零**出现在共享库 | 跨库查询额外延迟 | 用户是否感知双库 | `[POC-3]` |
| F4 | 规则分诊 | false-share 上界、coverage、false-private | 每句 <1 ms | 卡片量/百条事实 | `[POC-4]`（60 条）+ `[POC-6]`（1,467 条，coverage 29.2%） |
| F5 | LLM 提议层 | 与规则冲突时**规则赢**；建议稳定性 | 每候选 1 次调用 | 接受率、编辑距离 | 自建卡片集（n≥200） |

| F10 | 检索/提示词整体 | 逐能力正确数 | promptChars、墙钟 | — | LongMemEval-S 500 × 4 重复 |

### 6.3 两个"仪器"指标（外部集测不到）

1. **噪声底**（已建成）：同配置两次，逐题配对，MR −2 / TR −4，答案层毛变化 13.6%、状态层 11.8%。
2. **false-share 上界**（已建成）：零次观测 → Wilson 95% 上界。`0/12 → 24.2%`；`0/60 → 5.9%`；
   `0/600 → 0.6%`。**产品文案只能引用上界。**

## 7. 消融计划

通用形式：**leave-one-out on a paired roster** —— 同一批题、同一窗口、只少一个部件，用噪声带判定。

### 7.1 披露与边界（部分已有数）

| 机制 | 关掉它 = | 判定门槛 | 现状 |
|---|---|---|---|
| **A1 规则分诊** | 全部候选直接进共享 | 泄漏 >0 即证明承重 | ✅ **12/12 泄漏** `[POC-5]` |
| **A2 本地 NER** | 卡片不显示脱敏预览 | 误接受率差 ≥5pp | 未做（需 UI） |
| **A3 LLM 提议** | 卡片只有原句，没有原子 | 接受率差 ≥10pp | 🔶 **机制已实现并测过**（第 9 步）：0.5B 上 45/60 出提议、48 个原子、0 泄漏；**接受率差仍未测**（需真人 + 产品 UI，属于 F6 的可用性实验） |
| **A4 `defer` 默认私有** | `defer` 落共享 | 泄漏 >0 即失败 | ✅ 修补前 **3/12 泄漏**、只买到 +3 可达；补满召回后同一语料 **0/12**（04 §9.9）`[POC-5]` |
| **A5 scope 守卫** | 去掉读侧断言 | 注入时泄漏 >0 即失败 | ✅ guard off → 1/1 泄漏 `[POC-5]` |
| **A6 精确扫描 vs 索引** | 换 HNSW | p95 降 ≥50% 且 recall 不掉 | 未做（索引未实现） |
| **A7 int8 存储** | 全 f32 | 内存 ↑4×；延迟不作收益 | ✅ 内存 8× / 时间不单调 `[POC-2]` |
| **A8 Worker 边界** | 存储放主线程 | 若不可行则是约束不是消融 | 未做 |
| **A9 过期复核** | 过期事实继续检索 | 用 KU 子集量陈旧答案率 | 未做 |

**A1/A4/A5 是"不可省"型**：价值不在提升，而在**消除一类不可逆错误**，判定用绝对阈值（>0 即失败）。
它们也是本计划里唯一**已经出数**的三条。

### 7.2 检索与提示词（已全部关闭）

### 7.3 认知层（未接线，因此未消融）

`cortex-memory` vs 参考管线 是**决定认知层价值的关键消融**，也是预算投向的分水岭。
**在该结果出来之前，不应再向认知层追加新能力。** 预注册要求：双侧精确 McNemar `p<0.05` 且
`Δ>0`、全量 N=500、4 runs、`temperature: 0`、**零假设为预期**（"不劣于"而非"超过"），
一次 dispatch 不偷看不重跑。

## 8. 预注册纪律与停止规则

1. **写下来再跑**：假设、单变量、判据、停止规则，四项缺一不可。
2. **一次 dispatch**：不为更好的抽签重跑；三种结局各自预先定义后续动作。
3. **零假设也是预注册**：把"预期没有效应"写在派发之前，使 null 结果既不能被读成失败，
   也不能被事后调参转成正值。
4. **对照组必须逐字符成立**：否则不允许下"更好/更差"的结论。
5. **负向点估计必须复核**：`p=0.375` 不显著只说明分辨不出，不说明效应为零（conjunction 臂的
   教训：复核后判决比原读数更不利）。
6. **不再运行"结构上产不出"的实验**：`candidateSides` 的 question-only 回退只产 1 侧，而
   `discriminateContext` 需 ≥2 侧才标注 —— 该路径**结构性**产不出标注。先证明通道存在，再派发。

## 11. 风险、回滚与回归规则

1. **回归即回滚**：基准变差 → revert 或默认关闭。不接受"理论上应该更好"。
2. **一次只动一个变量**：配置行必须能说清这一轮动了什么；多变量同动视为无效实验。
3. **不做"更谨慎"式对策**：对"配置无法抵达测量"这类系统风险，对策是**双向断言闸**（dispatch
   input 与产物字段互相校验），不是让操作者更小心。
4. **门禁宁缺勿滥**：一条会在**正常运行**上报红的检查比没有检查更糟（它教会读者跳过输出）。
   被拒绝的候选检查要写进文档（例：`evidenceTurns > k`、turn 长度 > cap 都会在正常配置上触发，
   故不加入 `--audit`）。
5. **成本风险**：供应商限流契约见 02 §11；重试不得把已付费的嵌入重复付费。

## 12. 每轮迭代的输出契约

每轮必须交付，缺一即视为未完成：

1. **读数**：本轮结论 + run id + 配置行 + 区间/上界；
2. **变更**：改了哪些文件、为什么、有没有测试守着；
3. **缺口清单**：还剩哪些、每项**关掉它需要什么**（可执行的动作，不是"继续优化"）；
4. **下一步**：按依赖排序，并写明**为什么是这个顺序**（通常因为它是其他项的前置）；
5. **诚实边界**：本轮**没有**证明什么。

**"缺口为空"的定义**（达到它才能宣布设计阶段结束）：§10.1 的 9 条全部 ✅，且 04 §7 的
"未取证"表为空，且 01 §3 的调研矩阵里没有 `未调研` 行。

当前状态：**9 条全部 ✅**。"缺口为空"的定义因此满足，剩下的都是 §10.1.1 里那五条**设计边界**——
它们有限、有归属、有测法，且没有一条会改变架构决定。

判断"边界"与"缺口"的标准只有一条：**如果测出来的结果与预期相反，架构要不要改？**
要改的是缺口；只是调阈值、调 UI、调排期的是边界。按这条标准，上面五条都是边界。
