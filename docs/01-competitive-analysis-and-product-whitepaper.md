## 0. 结论先行（TL;DR）

1. **领域状态**：智能体记忆的"外存"（存储-检索）在 2026 已基本解决，Mem0/Zep/Letta 生产就绪；但"大脑"（何时记、记什么、如何忘、怎么用）才刚破题，权威综述（arXiv:2512.13564）将 memory automation、RL 集成、多模态、多智能体、可信性列为五个前沿空白。

2. **Cortex 的定位**：不是"又一个向量记忆库"，而是**价值驱动的认知记忆层（Value-driven Cognitive Memory Layer）**——把"记忆的大脑"作为一等公民，用可插拔策略对抗存储-检索的三难，用跨学科数学工具（最优传输、Information Bottleneck、MDP/TD(λ)、Hebbian 动力学、FSRS 遗忘曲线、双时态建模）补齐竞品集体缺失的认知能力。

3. **复刻 ≠ 融合**：Mem0 的通用抽取、Letta 的 Agent 自主、Zep 的时序图谱、A-MEM 的自组织、Mem-π 的参数化是**五条相互排斥的架构赌注**。Cortex 选择"检索式可溯源 + 价值驱动 + 异步巩固"这条主线，其余能力以可插拔策略实现，避免"融合所有竞品优势"的复杂度灾难。

4. **创新超越的三把刀**：① 主动弃权 + 价值驱动写入（对标 BEAM-10M Abstention 35.7、LongMemEval ABS，竞品几乎空白）；② 检索即巩固 + 异步巩固通道（Hebbian + FSRS，理论护城河最深）；③ 时序知识更新 + 冲突消解的可扩展化（对标 BEAM-10M knowledge_update ~26、contradiction ~40，Zep 已证方向但成本太高）。

5. **成为行业标杆的路径**：在权威基准（LoCoMo / LongMemEval / BEAM / MemSecBench / MemoryAgentBench / AMB）上以**真实、公平、科学**的方式（min/max/avg + t-test + 消融）全面超越竞品，同时以 Node + 浏览器双端、零外部服务依赖的嵌入式能力形成工程差异化。

> **关于第 4 点的校正**：② 的原始表述含 "最优传输 + TD(λ)"，现已移除。
> 两者的实际状态分别是「已实现未接线」与「未实现」。理论护城河的论述保留，
> 但**护城河目前是设计而非交付**——把它当作既成事实是本次审计发现的核心问题。

## 1. 产品定位

| 维度 | Cortex 定位 |
|---|---|
| **是什么** | TypeScript-first 的智能体记忆中间件，同时支持 Node 与浏览器 |
| **不是什么** | 不是独立数据库、不是独立向量库、不是 LLM 框架、不是垂直编码 Agent |
| **核心价值** | 把"记忆的大脑"（选择、巩固、遗忘、弃权、冲突消解、时序）做成可复用的、可插拔的、可溯源的认知层 |
| **差异化** | 嵌入式优先（better-sqlite3）+ 远程可扩展（PostgreSQL/pgvector）+ 浏览器原生（sql.js/IndexedDB），无外部服务依赖 |
| **目标用户** | 需要长期记忆、个性化、跨会话一致性的 Agent 构建者（编码 Agent、个人助理、多智能体系统、RAG 增强） |

### 1.1 与竞品的定位差异

- **Mem0** = 通用记忆层（"记忆的 MySQL"），认知能力浅；
- **Letta/MemGPT** = Agent 自主记忆操作系统，工程复杂度最高、最贵；
- **Zep/Graphiti** = 时序知识图谱记忆，时序最强但构建成本高；
- **A-MEM** = 自组织笔记，多跳最强但学术阶段、无托管；
- **Cortex** = **认知记忆层**：把上述各家的"认知亮点"（Zep 的时序、A-MEM 的关联、Letta 的自主、Mem-π 的弃权）以可插拔策略吸收，但用统一的"价值驱动 + 异步巩固 + 可溯源"架构承载，而非架构杂糅。

#### 2.1.1 新增关键情报：Exabase M-1（2026-05）

**这是当前最值得复刻的对象**，因为它用**比竞品小 4–6 倍的阅读器**（Gemini 3 Flash）
拿到 **96.4%**，登顶 LongMemEval。

| 深度 | 总分 | 知识更新 | 多会话 | 单会话(助手) | 单会话(偏好) | 单会话(用户) | 时序 |
|---|---|---|---|---|---|---|---|
| top-10 | 90.8% | 96.2% | 85.0% | 100.0% | 93.3% | 100.0% | 84.2% |
| top-20 | 93.4% | 97.4% | 88.7% | 100.0% | 93.3% | 95.7% | 91.7% |
| **top-50** | **96.4%** | 97.4% | 94.0% | 100.0% | 96.7% | 98.6% | 95.5% |
| top-200 | 95.4% | 97.4% | 91.7% | 100.0% | 96.7% | 98.6% | 94.0% |

**三个可直接借鉴的工程点**：

1. **三阶段重建式检索**：① 语义 + 词法 + **时序显著性**联合打分（近期更易取，但高相关的
   旧记忆保留）→ ② 查询**重写并分解为多路并行检索**，各针对一个独立信息需求 →
   ③ 用**重要性 / 时序链解析 / 跨记忆一致性**重排，使最终上下文「不仅相关，而且内部
   自洽且顺序正确」。
2. **峰值出现在 top-50 而非 top-200**，说明排序有效——不靠暴力堆上下文。
3. **口径诚实**：500 题统一通用提示词、无按题类型定制，并**主动披露**基准本身含至少
   4 道错题、已上报 2 道。

> **对 cortex 的直接含义**：M-1 的第三阶段（**一致性重排**）与第二阶段（**多路并行
> 分解**）正是 cortex 完全缺失或极浅的部分。cortex 当前没有重排，查询扩展每查询仅
> top-3。详见 [08 阅读器判断再研究](08-reader-parity-analysis.md) 与
> [07 SOTA 推进计划](07-sota-roadmap.md)。

#### 2.1.2 关键情报：Supermemory ASMR（2026-03）

用 **3 个 Observer Agent**（按 6 维度并行抽取）+ **3 个 Search Agent**（直接事实 /
语境线索 / 时间线重建）**完全替代向量检索**，纯内存运行。回答阶段两种变体：8 条专家
prompt 并行（98.6%）或 12 Agent 投票聚合（97.2%）。

其三条结论值得记录：**Agent 检索优于向量搜索**、**并行处理是效率核心**、
**专业化分工胜过通用模型**。

> **引用时必须标注的偏差**：ASMR **未用于其核心生产系统**；且「任一路答对即算对」的
> 多路择优在真实部署中无对应裁判，且需 8–12 倍推理成本。**复刻 M-1，不复制 ASMR 的
> 择优策略。**

#### 2.1.3 cortex 自己的当前位置（2026-10-20，三次样本 + 逐能力均值 `39367801501`）

竞品表里的每一个数字都来自**各自的读取器、各自的提示词、各自的裁判**，因此它只能用于"谁在什么能力上强"，
不能用于"我们差多少"。本项目自己的对照是**同一份裁判、同一份数据、同一条参考管线**：

| 能力 | 参考管线（单次） | **cortex（均值，四次重复）** | 区间 | 并集（单次） |
| --- | --- | --- | --- | --- |
| IE 信息抽取 | 2/150 | **134.25** | 133–135 | 135 |
| KU 知识更新 | 0/72 | **62.5** | 60–64 | 64 |
| ABS 应弃答 | 30/30 | **29.25** | 29–30 | 30 |
| **MR 多会话推理** | **105/121** | **84.25** | **81–88** | 109 |
| **TR 时序推理** | 87/127 | **94.75** | **94–95** | 108 |
| 合计 | 224 | **405.0** | **397–412** | **446** |

> **这是均值，不是某一次读数。** 同一配置的三次运行给出名单均值 406 / 402 / 405；
> 单次读数的跨度可达 19 题（397–419）。`--caps` 现在把每个能力的 mean 与 min–max 直接写进产物。

**三条读法：**

1. **TR 领先参考管线约 7–8 题**（94.75 对 87），**MR 落后约 20 题**（84.25 对 105）—— MR 仍是最常被引用、
   也是唯一净负的能力。并集 446 是单次读数，39 题可回收（MR 25、TR 13、IE 1）。
2. **与竞品报告值不可直接相减**：Mem0 报告 LongMemEval 94.4、Exabase M-1 96.4、Supermemory ASMR ~99%（多路择优）；
   参考管线在**同一管线**上只有 224/500。**目标线是并集 ~446**，而不是"把 405 提到 94"。
3. **两条结构性差异已被测掉且不受噪声影响**：参考管线只检索用户轮（本 arm 采纳后用户占比 **100%**、
   窗口 144→174 turn），以及它的房间是 24,000（本 arm 48,000 已用尽边际）。
   结构性事实还有一条：**本基准的 gold 恰有一半是助手轮**（`totalAll/total = 2.0`，120/121 与 125/127），
   所以只读用户轮按构造丢掉一半 gold，而准确率没有下降 —— 被丢掉的半边是复述。

### 2.2 四大根本分歧（记忆载体与写入权）

| 路线 | 代表 | 主张 | Cortex 取舍 |
|---|---|---|---|
| LLM 抽取 + 外部存储 | Mem0, Zep | 记忆在外部，检索获取 | ✅ 采纳（可溯源是底线） |
| Agent 自主管理 | Letta | 写入权交模型 | △ 部分采纳（写入权以"策略"形式可插拔，默认价值驱动） |
| 记忆自组织 | A-MEM | 记忆网络自我演化 | ✅ 部分采纳（巩固通道的灵感来源，但异步而非同步） |
| 经验参数化 | Hindsight, Mem-π | 蒸馏进参数 | ❌ 不采纳为主路线（黑盒、不可溯源、训练贵），仅作研究对照 |

### 3.2 复刻学习整合矩阵（哪些竞品的哪些功能，为什么）

| 来源竞品 | 复刻/学习的功能 | 为什么值得学 | Cortex 的改进 |
|---|---|---|---|
| **Zep/Graphiti** | 双时态边（valid_from/valid_until） | 时序/版本/冲突的原生解，已被 BEAM 验证 | 用增量 + 轻量分类器降低图谱构建成本（对标 Zep 成本痛点） |
| **A-MEM** | 链接网络 + 巩固（索引/合并/演化） | 多跳最强，Zettelkasten 是巩固通道的最佳参照 | 改为异步巩固（不阻塞写入），用最优传输约束保真 |
| **Mem0** | 多信号检索融合（语义+BM25+实体） | 工程上最成熟的相关性方案 | 叠加价值权重（value-aware），而非纯相似度 |
| **Letta/MemGPT** | 写入权交模型（自主分页） | 最灵活，能表达"何时该记" | 把写入权抽象成可插拔策略，默认价值驱动，避免每次额外 LLM 调用 |
| **HeLa-Mem** | 赫布动力学 + 显著性函数 + 跨层蒸馏 | 检索即巩固的数学化标杆（ACL 2026） | 叠加 FSRS 遗忘曲线（**TD(λ) 为规划项，未实现**），规模化优化 |
| **Mem-π** | ABSTAIN 弃权 token | 主动弃权是核心创新 | 用检索式（非参数化）实现弃权，保持可溯源，规避训练成本 |
| **MemOS** | provenance + 生命周期 + 访问控制 | 可溯源合规最强 | 用 provenance DAG + 不可变日志，轻量化实现 |
| **TiMem** | 分层记忆 + 召回冗余压缩 | 成本/延迟优化有据可查 | 用在线算法/缓存分层，自适应降级 |
| **HippoRAG2** | KG 引导多跳检索 | 多跳检索强 | 用轻量图 + 扩散激活替代重 KG。**注：图扩散激活接入 TR 已实测回滚，路线关闭** |
| **HyperMem** | 超图（高阶关系） | 多主体共同事件的表达 | 作为关联图的可选高阶扩展 |
| **Hindsight/ReMe** | 失败轨迹作为负样本 + 可复用模式 | 抗膨胀、从失败学习 | 纳入巩固通道的负样本信号 |
| **Exabase M-1** | **三阶段重建式检索 + 查询分解 + 一致性重排** | **用小 4–6 倍的阅读器登顶 96.4%，证明管线 > 阅读器** | 直接实施：补齐重排与多路并行分解（cortex 当前缺失） |
| **Supermemory ASMR** | **专用抽取通道 + 多 Agent 主动检索** | 「专业化分工胜过通用模型」，绕开语义相似度陷阱 | 按维度分通道抽取；**但不复制其多路择优**（基准口径偏差） |
| **QRhead / ICR** | 读者侧重排与迭代检索（8B 级） | 证明 8B 阅读器配合好检索可达 85.8 Recall@5 | 作为轻量阅读器档位的参照 |

### 3.3 为什么选择"复刻这些"而非其他

- **只复刻"有权威基准背书"的能力**：时序（LoCoMo temporal / BEAM）、多跳（LoCoMo multi-hop）、弃权（LongMemEval ABS / BEAM abstention）、知识更新（LongMemEval KU / BEAM）、冲突消解（BEAM contradiction）。没有基准背书的"炫技"一律不引入。
- **复刻的是"认知机制"，不是"架构"**：例如复刻 Zep 的双时态，但不用它的全量 LLM 图谱构建；复刻 HeLa-Mem 的赫布动力学，但不用它的单层图，而是融入四层记忆。
- **避免复刻"黑盒参数化"**：Mem-π/Hindsight 的参数化记忆不可溯源，与 Cortex 的可溯源底线冲突，只作研究对照。

## 4. 创新与超越（如何超越所有竞品，为什么）

### 4.1 三大创新主线

#### 创新 1：价值驱动记忆 + 主动弃权（Value-driven Memory with Abstention）

- **超越对象**：Mem0（无弃权）、Mem-π（有弃权但黑盒）、Letta（自主但贵）。
- **机制**：把"是否写入 / 是否检索 / 是否作答"统一建模为 **MDP 决策**，用**习得效用函数** `U(query, memory)` 替代余弦相似度；弃权 = 效用低于校准阈值 τ；弃权置信度用贝叶斯后验校准（temperature/Platt scaling）。
- **为什么能超越**：BEAM-10M Abstention 上 Mem0 仅 35.7，竞品均无生产级弃权；Mem-π 的 ABSTAIN 未在标准基准验证且不可溯源。Cortex 用**检索式可溯源**实现弃权，直接对标公开分数，可证伪、可复现。
- **实现状态**：`decideWrite` / `decideRetrieval` 已实现且有测试，但**不在评测路径上**；
  `defaultValueFunction` 目前是三项启发式（`confidence × sourceTrust × recency`），
  **并非 MDP/TD(λ) 学习所得**；Platt / temperature 校准**未实现**，阈值是固定常数。

#### 创新 2：异步巩固通道 + 检索即巩固（Consolidation + Retrieval-as-Consolidation）

- **超越对象**：A-MEM（同步巩固、贵）、HeLa-Mem（无生产化、未规模化）、Mem0/Zep（无独立巩固通道）。
- **机制**：独立后台 worker（"睡眠"进程）执行：赫布边权更新（显著性函数 + 环路抵消正则化）→ FSRS 遗忘曲线衰减 → 最优传输约束的跨层蒸馏 → TD(λ) 资格迹沿记忆 DAG 信用分配。
- **为什么能超越**：这是领域最大理论空白（四层动力学不统一），权威综述列为前沿，竞品几乎空白；跨学科工具成熟但未迁移，是最深的护城河。
- **实现状态**：`consolidate()` 实际只做三件事——**FSRS 状态更新、共激活边强化、阈值遗忘**。
  最优传输蒸馏 `sinkhorn` 已实现且有测试但**从未被调用**（唯一引用者是 barrel `index.ts`）；
  **TD(λ) 全仓库不存在**，无资格迹、无信用分配。该能力**不在评测路径上**。

#### 创新 3：时序知识更新 + 冲突消解的可扩展化（Scalable Bitemporal + Contradiction）

- **超越对象**：Zep（时序最强但贵）、Mem0（时序弱）。
- **机制**：双时态事实 `(s,p,o,valid_from,valid_until,source,confidence)` + 增量边模型（高置信直接写、低置信回退 LLM）+ 贝叶斯证据融合冲突消解。
- **为什么能超越**：BEAM-10M knowledge_update ~26、contradiction ~40 是公开硬伤；Zep 已证方向正确但成本高，Cortex 用增量 + 轻量分类器把成本降下来，形成"同样正确、更便宜"的差异化。

### 4.2 工程差异化（Node + 浏览器双端 + 零外部依赖）

| 竞品 | 部署形态 | Cortex 优势 |
|---|---|---|
| Mem0 | 云服务 / Python 优先 | TypeScript 优先，嵌入式可离线 |
| Zep | 云服务（Go） | 嵌入式 + 远程双模式 |
| Letta | 服务端（Python） | 浏览器原生（隐私优先场景） |
| A-MEM/MemOS | 学术/企业服务 | 零外部进程依赖，npm 即装即用 |

### 4.3 为什么 Cortex 能成为行业标杆

1. **有公开可证伪的靶心**：BEAM-10M abstention 35.7 / knowledge_update ~26 / contradiction 40，任何方案都能直接对比并做 t-test，不靠自吹。
2. **认知层竞争几乎空白**：权威综述列出的五个前沿，领军产品几乎都没做，Cortex 卡位最早。
3. **跨学科工具迁移是典型"工具在手、问题未解"**：最优传输、IB、TD(λ)、Hebbian、FSRS、双时态在各领域成熟，迁移到 Agent Memory 是低垂果实。
4. **工程标准极高**：Node + 浏览器双端、可插拔存储/LLM/Embedding、嵌入式优先、≥95% 测试覆盖率、无 mock、TDD、CI 真实全绿——这些工程纪律本身构成壁垒。

## 5. 风险与边界（诚实声明）

1. **"融合所有优势"是陷阱**：Cortex 明确选主线（价值驱动的认知记忆层），其余能力可插拔，不做架构杂糅。
2. **主动弃权的阈值校准难**：需留出集 grid-search + 校准曲线，且必须用三次独立运行 + 显著性检验验证，拒绝单次偶发命中。
3. **巩固通道计算代价**：赫布更新 + OT 蒸馏规模化后昂贵，需批量异步 + 局部邻域更新 + 亚线性规模约束。
4. **benchmark 报告值的可信度**：Mem0/Zep/Letta 的分数来自 vendor/论文单侧报告，Cortex 的对标必须自己复现基线，不能直接采信。
5. **参数化记忆路线不采纳**：Mem-π/Hindsight 的"记忆蒸馏进参数"与可溯源底线冲突，仅作研究对照，不投入工程。
6. **设计意图与已交付能力必须分开陈述（2026-09-20 新增）**：本次审计发现，把规划中的机制
   写成已完成能力，会让路线图在被实测否定后仍继续推荐该方向。**因此本文所有能力描述必须
   携带实现状态**，且任何基于本文的排期都要先核对 §3.1.1。
7. **认知层可能被证伪**：`cortex-core` 的认知层从未在评测路径上运行过，因此其净贡献
   **未知**（既未被证明有效，也未被证明无效）。在补齐组合层并完成消融之前，不应假设它
   带来增益——图扩散激活的实测回滚（TR 77.95% → 70.87%）正是一个"理论上应当有效"却实测
   有害的先例。
8. **"配置无法抵达测量"是自研基准的固有风险（2026-09-21 新增）**：与竞品对照不同，
   Cortex 的每一分都来自自己搭建的测量链路，而这条链路横跨 TypeScript 与 Python、
   跨越 dispatch → workflow → CLI → 产物四层。**任何一层的静默丢弃都不会报错**：
   GitHub 接受未声明的 dispatch input、运行照常启动、产物照常产出，唯一出错的是
   产物描述的是意图中的配置而不是实际应用的配置。这类偏差已出现三次（第 38 轮两次、
   第 44 轮一次），每次都在更外侧一层。**对策不是更谨慎，而是双向断言闸**
   （`tools/__tests__/test_dispatch_inputs.py`，三次注入验证）。
   **对竞品对照的含义**：Cortex 自报基线的可信度依赖这条链路的完整性，
   因此在引用任何自测数字时，产物必须同时携带其配置。这也是与 vendor 单侧报告
   （上文第 4 条）在方法论上真正拉开差距的地方——不是分数更高，而是**分数的来源可复核**。

## 部署形态与信任模型（2026-10 增补）

白皮书此前假定"一个服务端、一份记忆库"。浏览器侧可行性落地后，产品实际支持四种形态，
而它们的分歧不在功能，在**数据在哪里、谁能看见**：

| 形态 | 数据位置 | 适用 |
| --- | --- | --- |
| 纯浏览器 | 只在用户设备（OPFS） | 个人助手、隐私优先、离线 |
| 纯服务端 | 只在你的服务器 | 团队知识库、多端同步 |
| 双端读合并 | 私有在本地、共享在远端 | 个人 + 团队并存 |
| 双端写分诊 | 同上，写入时决定去向 | 同上，且需要"这条能不能共享"的判断 |

三条定位声明随之确定，且都有实测支撑（见 [14](14-evidence-register-and-poc.md)）：

1. **端侧能跑**：SQLite-WASM 在 Chromium 里跨浏览器重启保住数据，写入约 5.7 万行/秒；
   精确向量检索 6 万条 × 384 维 22 ms（p50）。
2. **隐私不是"我们承诺不看"，是"数据不出去"**：私有事实默认落本地，共享写入需要用户点一下。
3. **不把"该不该说"交给模型**：外部基准实测前沿模型在该判断上违规率最高 69%、且随使用累积；
   本产品的分工是**模型抽取、规则披露、用户盖章**。
