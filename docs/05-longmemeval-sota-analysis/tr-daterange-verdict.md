## 根因：一个时间窗口并不能唯一确定那个事实

追加每一个窗口内的回合提高了召回却降低了精确率。两道受损的题
都同时拥有其正确回合*和*另一个同窗口事件
（5K run；幼儿园毕业典礼）。扩宽召回把
干扰项拉进了上下文，而 LLM —— 那时必须在
两个窗口内事件之间选择 —— 挑错了。那个选择正是
DeepSeek 执行得较弱的语义判断，这就是为什么单靠时间窗口
无法替代它。

这是对 Hindsight Tempr 单实验臂版本的**精确证伪**：
Hindsight 通过事实级发生区间 + 交叉编码器重排 + 图遍历收窄到
唯一事实，而非通过一个裸的头部日期窗口。在本基准中，
单靠一个日期范围就是一次精确率损失。
