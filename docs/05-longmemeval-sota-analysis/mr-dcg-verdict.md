## 1. 判决

**拒绝 —— DCG 改动以显著幅度使 MR 回归。** `51b573f` 已被回退（`a52628f`），从而恢复
max-turn 打分。该负面结果作为证据保留：对于 LongMemEval-S 的多会话问题（它们以单一事实的
计数/聚合为主），单一最佳轮次分数优于排名折损聚合。

## 2. 机制端点 — MR 准确率

| 实验臂 | 逐运行正确 / 121 | 均值 |
| --- | --- | --- |
| control（max） | `[97, 94, 94, 88]` | 93.25 = 77.07% |
| treatment（DCG） | `[93, 87, 85, 89]` | 88.50 = 73.14% |

差值 **−4.75 题/运行 = −3.9pp**。针对下降方向做精确置换检验：约 2/70 = **p ≈ 0.029**
（显著回归）。

MR 弃权略有上升（9.75 → 10.75/运行），与 DCG 让更嘈杂的会话进入召回窗口并把证据轮次挤出
一致。

## 4. 为何会回归

预先注册的权衡判定 DCG 不利。LongMemEval-S 的 MR 题大多是单一事实的计数与聚合，其中正确
的证据是**一个**强轮次，会话其余部分都是噪声。DCG 会让一个有若干中等相关（噪声）轮次的
会话压过一个有一个强相关（证据）轮次的会话，从而稀释注入的上下文。`max` 才是匹配本基准
MR 形态的正确归约方式。

这是一个**有价值的负面结果**：它实证确认了 `max`-turn 打分在本基准的 MR 上是局部最优的，
并排除了把 EmergenceMem/AgentOS 的 DCG 启发式作为可迁移收益的可能。
