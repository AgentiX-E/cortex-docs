# P24 §A — 在一个已准入的会话内部，哪些轮才重要

仪器：`analysis/scripts/p24_turn_class.mjs`。数据：运行 `35004814319`
（`4955d8e`），MR 行，即唯一携带证据会话内容的行。n = 121 道题，9,028 个已准入
轮，0.1% 没有可解析的角色行（截断产物）。

## 为什么要测量这个

P23 §5 证伪了对覆盖率相关性的线性解读：将题目移入 100% 覆盖率并未以固定速率换来
准确率，因为那些*因某项修复而*到达该处的题目更难。这使目标从准入*多少*轮变为准入
*哪些*轮。这是对第二个问题的首次测量。

## 在读取任何结果之前发现并修复的两处仪器 bug

二者都产出了看似合理的零值，这正是它们被记录在案、而非被悄悄修补的原因：

1. **轮解析器只匹配了两种呈现形式中的一种。** 单会话路径发出
   `[YYYY/MM/DD] user: ...`；多会话路径发出 `[YYYY/MM/DD (Ddd) HH:MM] user: ...`。
   一个锚定在 `[\d/]+\]` 上的模式将每个 MR 轮都解析为 `role: 'unknown'`，因此
   `userTurns` 与 `assistantTurns` 都读作 0，看起来像是关于数据的一项发现。该解析器
   现可处理两者，并且若超过 2% 的轮无法解析，脚本会**以非零码退出**。
2. **重叠方向被搞反了。** 问“会话有多大比例落在此轮中”在结构上约为 0（一个会话
   约 12,000 个 shingle，而一轮只是其中一小片），因此证据覆盖率在全部 9,028 个轮上
   都读作 0。有用的方向是“在此轮中，有多大比例落在参照之中”。

阈值是依据实测分布校准的，而非人为选定：证据覆盖率 p50 0.560 / p75 0.710 /
p90 1.000，因此切点取 0.5。答案覆盖率是 p50 0.000 / p95 0.013 / 最大 0.323
—— shingle 比值对一条简短的标准答案短语不可用，因此“陈述了答案”采用子串检验。

## 发现 1：准入承载答案的那一轮与更低的准确率相关

| 分组 | n | 准确率 | 95% CI |
|---|---|---|---|
| 有承载答案的轮 | 44 | 84.1% | [70.6, 92.1] |
| 没有 | 77 | 89.6% | [80.8, 94.6] |
| 有 ≥2 个承载答案的 | 29 | 79.3% | [61.6, 90.2] |

在三个分组间单调（89.6 → 84.1 → 79.3），且**不是规模混淆**：平均提示词体积是平的
（17,343 / 17,373 / 17,262 字符），平均已准入轮数也是平的（74.9 / 74.1 / 73.3）。
因此该效应追踪的是*哪些*轮，这正是 P23 §5 所问的问题。

**使这无法成为结果的保留意见：** 置信区间大幅重叠，该比较是观察性的而非配对的，
并且 MR 是一个已知会因增加轮数而稀释聚合的能力。这是一个待做配对检验的假设，不是
一根杠杆。

## 发现 2：我最初在此读出的“覆盖率最优值”是一个假象

将 `evidenceBearing` 切成三个桶后得到 83.9%（≤40 轮）→ **95.1%**（41–60）→
75.9%（>60），读起来像一条干净倒 U 形曲线，带有一处内部最优。**十分位网格证伪了它：**

| 十分位 | evBear | n | 准确率 |
|---|---|---|---|
| d1 | 13–30 | 13 | 92.3% |
| d2 | 31–37 | 13 | 76.9% |
| d3 | 38–43 | 13 | 84.6% |
| d4 | 43–47 | 13 | 100.0% |
| d5 | 48–51 | 13 | 92.3% |
| d6 | 51–56 | 13 | 92.3% |
| d7 | 56–60 | 13 | 100.0% |
| d8 | 60–66 | 13 | 76.9% |
| d9 | 67–74 | 13 | 84.6% |
| d10 | 75–87 | 4 | 50.0% |

相邻十分位摆动于 76.9 → 100.0 → 84.6 → 100.0 → 76.9。二次拟合是**凸的**（无内部
峰值），Pearson 仅为 −0.108，而所谓“最优值”恰好落在人为 40/60 切点的边界上。
三桶的形状是在 121 个点上由分桶位置制造出来的。

唯一一致的信号是最薄的那个十分位：**evBear 75–87 → 50%（n=4）**，且其平均已准入
轮数是所有十分位中最高的（87.0）。这与 P23 的轮数分带——轮数过多——相符，而与
覆盖率最优值不符。n=4 承载不了它。

## 状态

仅为假设。在 n=121 时，`evidenceBearing` 与正确性**没有**单调关系；`answerBearing`
则有一个一致的负向关系，它在规模控制下依然成立，需要一次配对检验。两者目前都不
应被用来更改任何默认值。
