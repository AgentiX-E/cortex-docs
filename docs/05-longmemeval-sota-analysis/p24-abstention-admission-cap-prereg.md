## 什么会证伪该说明

- **ABS 在平均轮数 ≤ 30 时不变于 24/30** → P23 §3a 中的轮数机制是错的。弃权
  决策届时将由上限未触及的某个东西驱动，而该机制必须
  从新运行重新推导，而不是再次打补丁。
- **ABS 低于 24/30** → 该上限使提示词挨饿（`hits` 模式准入的是
  一个不同的轮集合，而不仅仅是更少的轮），该改动必须回退。
- **IE / MR / KU / TR 中任何一个移动超出其历史运行间噪声** →
  范围限定泄漏了，该改动不如所声称的那样是弃权局部的。

## 途中更正

P23 §3 把 ABS 损失归因于"证据会话被完全准入"。那无法
从产物中推导出来（ABS 行不携带证据字段），并已在 P23 §3a 中撤回。替代说明是轮数分带，而上面的 P1–P3
就是它的检验。
