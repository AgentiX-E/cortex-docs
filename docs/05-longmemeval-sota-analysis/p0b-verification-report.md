## 4. 阴性对照漂移（必须透明披露）

MR/KU/TR 是本补丁**逐字节不可达**的路径（各自拥有独立的提示与解析器），然而它们的运行级
delta 为 −1.79 / +3.59 / +1.44pp（均值 +1.08pp）。

这表明：**在 n=4 vs 3 的同时刻运行级别上，各能力精确率携带 ±2–3.5pp 的噪声/漂移。** 含义：

- KU 的 +3.59pp（置换 p=0.0286）是一个**假阳性**——代码完全相同却"显著"，这表明在
  n=4 vs 3 时，运行级的精确置换检验缺乏分辨率，不能作为归因依据。
- IE 的 +4.78pp 必须打折：漂移校正后约为 **+3.7pp**（+4.78 − 1.08），仍是一个明确的增益，
  且 IE 有"完全分离 + 机制锁定"的双重支撑。
- 总体的 +1.87pp 同样应视为"方向正确、量级不确定"（p=0.057）。

**方法论更正**（将写入后续迭代）：在本实验的规模上，运行级各能力精确率 delta 不能作为显著
性证据；**主要端点必须采用机制性端点**（弃权率、崩塌率等确定性测度），准确率仅作为带有噪声
下限的描述性估计。
