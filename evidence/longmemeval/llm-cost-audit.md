# LLM API 调用与成本审计

**结论先行**：一次完整基准运行（`runs=1`，全部 500 题）会发出约 2,460 次 LLM 调用。
两项改动——(1) 对高置信度问题共享 baseline/feature 的答案，(2) 让三项诊断消融可跳过
——可在零准确率影响下削减约 57% 的账单。阅读器应保持为 **V4-Flash**，它比 V4-Pro 便宜
3.1 倍，且当前得分更高（83.95% vs 78.40%）。

## 1. 调用都花在哪（每次完整运行，runs=1）

| 阶段 | 扩展调用 | 答案调用 | 备注 |
|---|---|---|---|
| 主 QA（baseline + feature） | 500（共享缓存） | ~999 | baseline 与 feature 各自回答全部 500 题 |
| MR 聚合消融 | 121 | 242 | legacy vs CoT，配对 |
| TR 时序引擎消融 | 127 | 254 | LLM vs 确定性，配对 |
| KU 双时态消融 | 72 | 144 | CoT vs LLM-extract，配对 |
| **小计** | **820** | **~1,639** | |
| **总计** | | **~2,460** | 不含判分器（见 §4） |

一次 4v4 A/B 要把这个跑 8 遍 ⇒ 约 19,700 次调用。

## 2. 成本估算（V4-Flash，每次运行）

DeepSeek V4 定价（每 1M token）：Flash 输入 `$0.14` / 输出 `$0.28`
（缓存命中的输入 `$0.0028`）；Pro `$0.435` / `$0.87` —— **Pro 是 Flash 的 3.1 倍**。

| 组成 | Token 量 | 成本 |
|---|---|---|
| 答案输入（~1,639 × ~1.5K） | ~2.5M | ~$0.35 |
| 扩展输入（~820 × ~0.12K） | ~0.1M | ~$0.01 |
| 输出 | ~0.04M | ~$0.01 |
| **总计** | | **~$0.37/运行**（一次 4v4 A/B 约 $3） |

Pro 约为 $1.15/运行（一次 4v4 A/B 约 $9），**而且得分更差** —— 见 §5。

## 3. 优化计划（按 ROI 排序）

### P0 — 共享 baseline/feature 的答案（约 −18% 总量）

`enableAbstention` 并**不**改变提示词：`nl-naive-baseline` 与 `nl-abstain-feature` 都在
相同的 retrieved context、相同的 temperature 下，用相同的 `DEFAULT_ABSTAIN_TOKEN` 调用
同一个 `buildQaPrompt`。因此对于 feature 系统确实作答的每一道题
（`top1Score ≥ threshold`），baseline 与 feature 产生的 LLM 调用是**逐字节完全相同**的
—— 也就是约 500 次 feature 调用中有约 447 次是重复的。

增加一个以提示词为键、在两个系统间共享的答案缓存；feature 运行随后复用 baseline 的答案，
而不是重新计费。

### P1 — 让三项消融可跳过（约 −39% 总量）

MR/TR/KU 消融是诊断性的（它们隔离各机制的贡献），不属于头条 SOTA 数字的一部分。一个
`--skip-ablation` 标志（或 `SKIP_ABLATION=1` 环境变量）可在只关心分数时砍掉 960 次调用。

### P2 — 利用 DeepSeek 的自动前缀缓存

DeepSeek 会自动缓存提示词前缀（缓存命中的输入便宜 50 倍）。把稳定的指令前导放在最前、
可变的 retrieved context 放在最后。查询扩展提示词已有稳定前导，是这里最容易的收益点。

### P3 — 让 V4-Flash 继续担任阅读器

Pro 是 Flash 的 3.1 倍且当前得分更低。只有在思考模式实验证明并非如此时才重新考虑（§5）。

## 4. 判分器已经很便宜

`judgeScorer` 在归一化精确匹配与数值判决上会短路，因此 LLM 判分器只在残余情形上触发，
而 `createLlmJudge` 会按提示词跨系统、跨运行缓存判决。这方面无需进一步工作。

## 5. 阅读器矩阵（已测 vs 未测）

| 阅读器 | 非思考 | 思考 |
|---|---|---|
| V4-Flash | **83.95%** ✅ 已测 | **未测** —— 成本最低的候选 |
| V4-Pro | 78.40% ❌ 已测（更差） | 未测 —— 需要更长的截止时间 + 3.1 倍成本 |

**V4-Flash + 思考是 ROI 最高的未测单元**：它保留 Flash 良好的指令遵循能力（正是 Pro
非思考所失去的），同时为 TR/MR 的算术题加入推理。它比 Pro 思考便宜 3.1 倍。
