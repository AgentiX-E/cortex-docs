# P26 — 弃权重试具有一个结构性的零收益

数据：运行 `35004814319`（`4955d8e`）与 `35019792901`（`0b0069a`），完整的
500 题 LongMemEval-S，`temperature = 0`。

## 1. 测量，做了两次

| 运行 | 路径 | 已武装 | 已触发 | 已恢复 |
|---|---|---|---|---|
| `35004814319` | MR | 121 | 0 | — |
| `35004814319` | 单会话 | 276 | **11** | **0** |
| `35019792901` | MR | 121 | 0 | — |
| `35019792901` | 单会话 | 379 | **12** | **0** |

**两次完整运行中共 23 次实际触发，0 次恢复。** P21/P23 关于该重试“是惰性的”这一
主张，是在它从不触发的 MR 子集上得出的；正确的陈述是：它**在单会话路径上触发，
且不转化任何东西**。

较新一次运行中这 12 次的能力分布：TR 7，IE 4，KU 1。全部 12 道都是可回答的题，其
标准答案不在提示词中，且全部 12 道都两次返回了光秃秃的 `UNANSWERABLE`。

## 2. 为何收益恰为零，而不只是很小

阅读 `respondWith`（`natural-language-memory.ts`，重试块）：

```ts
if (retryEnabled && detectBareAbstention(raw, abstainToken)) {
  const retried = await completeFresh(prompt);   // <-- the SAME `prompt`
  retryFired = true;
  if (!isAbstentionValue(retried, abstainToken) && parser(retried, abstainToken) !== null) {
    raw = retried;
  }
}
```

重新追问传入的是 `prompt`，未加改动。在 `temperature = 0` 下，提供方是确定性的
—— 代码库在其他地方恰恰依赖这一点，而 `p23_significance.mjs` 也记录了系统在此设置下
是确定性的 —— 因此第二次调用返回与第一次相同的文本。于是一次光秃秃的弃权以概率 1
复现。

**P(recovered) = 0**，这就是为何 23 次触发产生了 23 次未恢复。该重试并非表现不佳；
它不可能成功，而每次触发都要花费一次模型调用才能确立这一点。

这也解释了为何 `enableAbstentionRetry` 的消融在 MR 上报告 `+0.00%` 且
`0 control / 0 treatment` 次触发：该消融的范围（121 道 MR 题）与重试实际触发的
总体（单会话）互不相交。

## 3. 若要保留该重试，它需要变成什么

三个选项，按改动幅度排序：

| 选项 | 机制 | 风险 |
|---|---|---|
| **A. 删除它** | 移除该标志、该分支、`completeFresh` 以及该消融 | 丢失一个真实的缺陷信号：12 道可回答的题，模型在其中两次拒答 |
| **B. 重新追问不同的东西** | 在一次光秃秃的弃权上，改问一个*仅上下文*的提示词（“上下文对 X 是怎么说的？”）并解析那个 | 这是一个不同的机制，需要它自己的契约与它自己的测试 |
| **C. 仅放松缓存** | 保留完全相同的重新追问，但在 `temperature > 0` 下 | 已否决 —— 它买来的是噪声，且会使基准变为非确定性，从而破坏测试框架中的每一项配对统计量 |

**如果没有一次运行能显示该重试恢复了一道题，A 就是诚实的默认选项**，因为当前版本
是一个有保证的空操作，却要花费预算。**如果这 12 道题的总体值得针对，B 就是值得
构建的版本**，而它确实值得：这些题是可回答的，检索确实返回了东西，而失败在于模型
拒绝，而非证据缺失。

我不在此处在 A 与 B 之间作出选择。已经定下来的是：已发布的重试不可能起作用，而在
其消融报告 `+0.00%` 的同时发布它，比根本没有它更糟，因为该消融的范围使一个结构性
的零看起来像是一个经过测量的零结果。

## 4. 必须存在的测试

结构性主张应当被钉住，而不只是被论证：

> 用一个每次都返回光秃秃弃权的桩 LLM，`retryFired` 为真且回答仍是弃权 —— 即该重试
> 被*观察到*运行，并被*观察到*未恢复，因此任何使第二次调用产生差异的未来变更都
> 必须有意地更新此测试。

第二个测试应当断言真实运行中的触发次数由消融报告，而非仅 MR 的数字，这样那个曾
把此事隐藏了两次调查的范围限制就无法再发生。
