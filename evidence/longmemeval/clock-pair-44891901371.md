## 六次翻转落在哪里

`PREREGISTRATION-SESSION-CLOCK.md` §1.3 的富化签名是「一条回复打印 ≥3 个日期，且其中 ≥3 个相同」。
在这份产物上重算——数每道题送达轮次里互不相同的 `[YYYY/MM/DD` 时间戳：**93 / 121** 道题送达了
≥2 个互不相同的日期，与 `S16` 给出的同样是 93 道。

| 题 | 对照 → 处理 | 送达的不同日期数 |
| --- | --- | ---: |
| `46a3abf7` | 0.5 → 0.0（失） | 11 |
| `c4a1ceb8` | 1.0 → 0.5（失） | 11 |
| `gpt4_7fce9456` | 1.0 → 0.0（失） | **1** |
| `gpt4_a56e767c` | 1.0 → 0.0（失） | 11 |
| `92a0aa75` | 0.0 → 1.0（得） | 11 |
| `2e6d26dc` | 0.5 → 1.0（得） | **1** |

六次翻转里有四次落在被富化的族群上，所以机制确实触达了它；它把这四次推成「得 1 失 3」。
登记的否证条件 `P1`（「回归必须落在多日期题上」）被 `gpt4_7fce9456` 违反，而这个违反**正是一个
什么都不做的机制也会产生的形状**：121 道里 28 道（23%）是单日期题，四次丢失在这个族群上的期望
是 0.93 道。
